# Security Policy

## Supported versions

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Use GitHub's **Security → Report a vulnerability** private reporting flow for this repository. Include affected versions, reproduction steps, impact, and any suggested mitigation.

Please allow a reasonable period to investigate and publish a fix before public disclosure. Routine bugs that do not expose user data or cross a security boundary can use the public issue tracker.
