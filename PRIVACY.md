# Privacy Policy

Last updated: September 14, 2026

Octarine Web Clipper does not collect, transmit, sell, or share personal data. It has no analytics, advertising, tracking, account system, or remote content-processing service.

The extension reads the active web page only to extract content the user asks to clip. Processing and Markdown conversion happen locally in the browser. The result is passed to the locally installed Octarine desktop app through an `octarine://` deep link. Extension preferences and pending selections are stored locally using the browser's extension storage.

The extension requests broad site access because clipping must work on pages across the web. It does not use that access to build browsing histories or send page content to the developer. Website links and images retained in a clip may still load from their original hosts when viewed.

Questions or privacy reports can be filed through the repository's issue tracker. Security-sensitive reports should follow [SECURITY.md](SECURITY.md).
